# 🎬 YouTube Series - Modern IBM i API Development

> **Série TechServ** : *Build a Complete Service Management System - From Legacy RPG to Modern REST APIs*

## 📖 Vue d'Ensemble

Cette série YouTube de 20 épisodes démontre la modernisation concrète d'un système IBM i à travers le développement d'une application de gestion de services techniques (TechServ).

**Objectifs** :
- ✅ Montrer la transformation d'une PME fictive utilisant IBM i
- ✅ Développer des APIs REST production-ready avec ILEastic
- ✅ Créer des interfaces modernes (React-Admin + Mobile)
- ✅ Valider les patterns pour le futur générateur CMagic

## 🏢 Use Case : TechServ

**TechServ** est une PME spécialisée dans la maintenance technique (HVAC, électricité, plomberie) qui utilise IBM i depuis 20 ans.

**Problématique** :
- ❌ Interface 5250 peu ergonomique
- ❌ Pas d'accès mobile pour techniciens terrain
- ❌ Impossible d'intégrer outils modernes
- ❌ Difficulté recrutement développeurs RPG

**Solution** :
- ✅ APIs REST sur données IBM i existantes
- ✅ Interface React-Admin moderne
- ✅ App mobile techniciens
- ✅ Portail client self-service
