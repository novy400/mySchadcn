## 🛠️ Outils et Technologies

### **Frameworks & Libraries**
- **ILEastic** : Framework REST pour IBM i RPG
  - Repository : https://github.com/sitemule/ILEastic
  - Documentation : https://sitemule.github.io/ILEastic/
  
- **noxDB** : JSON parsing pour RPG
  - Repository : https://github.com/sitemule/noxDB
  
- **BOB** : Build automation IBM i
  - Repository : https://github.com/IBM/ibmi-bob
  - Documentation : https://ibm.github.io/ibmi-bob/

### **Frontend Technologies**
- **React-Admin** : Framework admin moderne
  - Site : https://marmelab.com/react-admin/
  - Documentation : https://marmelab.com/react-admin/doc/3.19
  
- **PWA** : Progressive Web Apps
  - Guide : https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps

  - Site : https://www.usebruno.com/
